**Build APIs at the speed of thought.**

Hoppscotch (formerly known as Postwoman) is an open-source alternative to Postman, created by Liyas Thomas while he was still a college student in Kerala, India. What started as a side project to build a lighter, faster API client has grown into a full-fledged API ecosystem used by over 500,000 developers worldwide.

#### **Why Hoppscotch is a Developer Favorite**

- **Lightning fast, browser-first** — Works instantly in any modern browser. No download, no setup, no account required. Just open and start testing APIs.
- **Multi-protocol support** — REST, GraphQL, WebSocket, Server-Sent Events, Socket.IO, MQTT — all from a single, clean interface.
- **Privacy by design** — All requests run locally in your browser. Your data never touches Hoppscotch's servers. No tracking, no telemetry.
- **Open-source & community-driven** — With 65,000+ GitHub stars and 500+ contributors, the project is transparent, auditable, and constantly improving.
- **Pro features when you need them** — Hoppscotch Pro adds team collaboration, API documentation generation, and environment sync — for teams that need more.

Hoppscotch has been featured on GitHub Trending multiple times and is backed by the GitHub Accelerator program. It's a proud example of Indian open-source talent building world-class developer tools.
