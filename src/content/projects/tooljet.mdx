**Ship internal tools at the speed of a startup — without the overhead.**

ToolJet is an open-source low-code platform founded by Navaneeth P.K. and Manish Kumar from Kerala, India. It lets engineering teams build custom internal tools — admin panels, CRUD apps, approval workflows, and operational dashboards — in minutes instead of weeks.

#### **What Makes ToolJet Powerful**

- **50+ built-in data source connectors** — PostgreSQL, MySQL, MongoDB, Firebase, Stripe, Shopify, Google Sheets, Slack, and more — just point and click.
- **Drag-and-drop UI builder** — Build rich interfaces with tables, forms, charts, kanban boards, maps, and custom React components — no frontend skills needed.
- **Code when you need it** — Use JavaScript and Python snippets inside your workflows for custom transformations, business logic, and API orchestration.
- **Self-host or cloud** — Deploy on your own infrastructure (Docker, Kubernetes, Railway) for full data control, or use ToolJet Cloud for a managed experience.
- **Granular access control** — Role-based access, audit logs, and SSO make it enterprise-ready from day one.

ToolJet has been adopted by thousands of companies globally, from Y Combinator startups to Fortune 500 enterprises. It's a proud Indian open-source project challenging incumbent platforms like Retool — and winning on transparency, pricing, and community trust.
