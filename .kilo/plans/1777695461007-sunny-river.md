# Plan: Fix Focus Outline on Hamburger Menu and Theme Toggler

## Problem

The hamburger menu button and theme toggler button maintain focus state (with a visible border) after being clicked, which only disappears when clicking elsewhere on the page. This creates a persistent visual artifact that degrades user experience.

## Investigation Steps

1. Locate the components containing these buttons using grep
2. Identify the CSS classes/styles responsible for the focus state
3. Determine the appropriate solution to remove focus after interaction

## Implementation Plan

1. The issue is in `src/styles/global.css` lines 31-33 where `*:focus-visible` applies outline styles globally
2. Buttons with focus issues: hamburger menu button (#mobile-nav-toggle) in `Header.astro` and theme toggle button (#theme-toggle) in `ThemeToggle.astro`
3. Fix the CSS by adding specific rules for these buttons that:
    - Remove focus outline for mouse clicks using `:focus:not(:focus-visible)`
    - Preserve focus outline for keyboard navigation using `:focus-visible`
    - Apply `outline: none` for mouse interactions only
4. CSS implementation details:
    - Add `#mobile-nav-toggle:focus:not(:focus-visible)` and `#theme-toggle:focus:not(:focus-visible)` selectors
    - Set `outline: none` for these selectors
    - Ensure the global `*:focus-visible` rule remains for accessibility

## Files to Modify

- `src/styles/global.css` - Add specific CSS rules after line 33 for the two button IDs

## CSS Changes

```css
/* Apply focus outline to all elements by default */
*:focus-visible {
    @apply outline-2 outline-offset-2 outline-primary-600 dark:outline-primary-400;
}

/* Remove focus outline for specific buttons after mouse click, preserve for keyboard navigation */
#mobile-nav-toggle:focus:not(:focus-visible),
#theme-toggle:focus:not(:focus-visible) {
    @apply outline-none;
}
```

## Validation

1. Test the fix by clicking the hamburger menu and theme toggler buttons
2. Verify the focus outline no longer persists after interaction
3. Ensure keyboard navigation accessibility is maintained if applicable
